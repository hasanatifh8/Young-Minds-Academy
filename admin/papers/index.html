Connect Supabase to start uploading

The admin dashboard stores papers and PDFs in your Supabase project. One-time setup:

  1. Create a free project at supabase.com.
  2. In SQL Editor, run the script in supabase/schema.sql. It creates the tables, the papers storage bucket and the admin-only access rules.
  3. In Authentication → Users, add a user for yourself, then run the "make yourself an admin" query at the bottom of the script.
  4. Copy the Project URL and anon public key from Project Settings → API into assets/vault-config.js.
